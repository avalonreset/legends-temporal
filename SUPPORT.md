# Support

Check [docs/AGENT-RECIPE.md](docs/AGENT-RECIPE.md), [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md), [docs/KNOWLEDGE-PACK.md](docs/KNOWLEDGE-PACK.md), and `legends-temporal --help` before opening an issue.

For defects in this module, open an issue at [avalonreset/legends-temporal](https://github.com/avalonreset/legends-temporal/issues). Include the module version (`legends-temporal version`), OS, Python version, `temporalio` SDK version, the command with placeholders for private identifiers, and the expected versus observed output.

Never post Temporal API keys, mTLS private keys, webhook URLs, private hostnames, or sensitive workflow payloads. Report security vulnerabilities through [SECURITY.md](SECURITY.md).

Temporal Server installation, Temporal Cloud account questions, and upstream SDK bugs belong with [Temporal's documentation and community resources](https://docs.temporal.io).
